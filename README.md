# Personal Finance Analysis

A Pandas-only personal finance analysis project using `personal_finance.csv`.

## What it covers
- Data inspection and validation
- Date conversion
- Income vs expense analysis
- Payment-channel analysis
- Category and essential/non-essential analysis
- Large transaction analysis
- Monthly spending
- Rolling averages
- City-level analysis
- Pivot tables and ranking operations

## Libraries
- pandas

## Files
- `Pandas_personal-finanace.ipynb`
- `personal_finance.csv`
> Visualization is intentionally not included in this project.
